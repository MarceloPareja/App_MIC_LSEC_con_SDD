# Research

## Decision: Android nativo con Kotlin
**Rationale**: Mejor compatibilidad de versiones y acceso a hardware.
**Alternatives**: Flutter, React Native.

## Decision: Servidor MVC en Java
**Rationale**: Requisito de constitución MVC.
**Alternatives**: Node, Python.

## Decision: TFLite para modelo externo
**Rationale**: Requisito del usuario.
**Alternatives**: ONNX, PyTorch.

## Decision: Streaming por paquetes con Retrofit/OkHttp
**Rationale**: Evita almacenamiento local.
**Alternatives**: WebSocket.
